# Base_de_conocimiento_entrega
Base de conocimiento vectorial para CODEFEST AD ASTRA 2026 (Etapa 1). Pipeline de preprocesamiento y chunking multiformato (PDF, JSON, CSV/XLSX, PBF, imágenes, TXT) con OCR, segmentación por oraciones con solapamiento, validación de integridad y salida en JSONL para indexación vectorial.
